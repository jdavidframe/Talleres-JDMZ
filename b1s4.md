### Problema

- **Variable X**: año de lanzamiento original de la canción.

### Fórmulas

$$
b = \frac{n\sum_{i=1}^{n} x_i y_i - \sum_{i=1}^{n} x_i \sum_{i=1}^{n} y_i}{n\sum_{i=1}^{n} x_i^2 - \left(\sum_{i=1}^{n} x_i\right)^2}
\qquad
a = \frac{\sum_{i=1}^{n} y_i - b\sum_{i=1}^{n} x_i}{n}
\qquad
\hat{y} = a + b\,x
$$

**Donde**:
- $n$ es el número total de canciones
- $x_i$ es el año de lanzamiento y $y_i$ la duración en segundos de la canción $i$
- $b$ (pendiente) indica cuántos segundos cambia la duración por cada año
- $\hat{y}$ es la duración que predice la recta para el año $x$

### Interpretación de la pendiente ($b$)

| Valor de b | Interpretación |
|------------|----------------|
| **b ≤ -3** | Disminución fuerte: más de medio minuto menos por década |
| **-3 < b < 0** | Disminución moderada o leve |
| **b = 0** | Sin tendencia |
| **b > 0** | Las canciones son cada vez más largas |

4. Explique cómo implementó el cálculo de $b$ y $a$. ¿Qué operaciones funcionales utilizó?

```scala
val n = canciones.size

val sumxy = canciones.map(c => c.Anio * c.Duracion).sum.toDouble
val sumx  = canciones.map(_.Anio).sum.toDouble
val sumy = canciones.map(_.Duracion).sum.toDouble
val sumx2 = (canciones.map(n => n.Anio.toDouble * n.Anio).sum)

val b = ((n*sumxy)- (sumx * sumy))/((n*sumx2)-(math.pow(sumx,2)))
val a = (sumy - (b*sumx))/n
def prediccion(x: Double) = a + (b*x)

prediccion(2030)
prediccion(2150)

```
Para realizar el calculo tanto de $b$ como de $a$ dividimos cada sumatoria en variables que luego utilizariamos para construir las formulas implementadas en scala. Ademas de los operadores basicos logicos que podemos encontrar en cualquier lenguaje de programacion como (+, -, *, / etc), usamos funciones para sumar valores (.sum) y para convertirlos en decimales (.toDouble). Todo esto nos permitio tener un manejo optimo de las operaciones necesarias para poder calcular la medicion.
